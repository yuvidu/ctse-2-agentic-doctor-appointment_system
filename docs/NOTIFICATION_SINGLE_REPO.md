# Single-repo layout (Notification)

All **Notification** agent code, tools, tests, and docs for this assignment live under **this repository root** (`New folder` as the project directory on disk).

The former standalone sibling folder `CTSE 2/Notification/` has been **retired** after its contents were merged here so there is a single import tree (`agents.*`, `tools.notification_tools.*`, `integration.*`) and one `pytest` suite under `tests/`.

If you still have an old `Notification/` checkout, delete it to avoid editing the wrong copy.
