# Single-repo layout (Notification + Booking)

All **Notification** and **Booking** agent code, tools, tests, and docs for this assignment live under **this repository root** (`New folder` as the project directory on disk).

The former standalone sibling folders `CTSE 2/Notification/` and `CTSE 2/booking agent/` have been **retired** after their contents were merged here so there is a single import tree (`agents.*`, `tools.notification_tools.*`, `tools.booking_tools.*`, `integration.*`) and one `pytest` suite under `tests/`.

If you still have old sibling checkouts, delete them to avoid editing the wrong copy.
